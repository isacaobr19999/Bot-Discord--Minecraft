# Banco de dados

O banco de dados guarda as identidades do site, jogadores, vínculos, códigos temporários, snapshots de status, eventos de integração, permissões, logs de auditoria e, em etapas posteriores, pedidos, cupons e entregas.

O modelo físico será mantido em `drizzle/schema.ts`; este diretório contém documentação complementar de dados e decisões de persistência.
